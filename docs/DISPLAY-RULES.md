# Правила отображения

- Выбирается одна группа `limitId`. По умолчанию `codex`, иначе первая доступная; явно выбранная исчезнувшая группа показывает «нет данных».
- При наличии `rateLimitsByLimitId` используется он. Пустой или отсутствующий набор допускает legacy `rateLimits`.
- Внутри группы окна сортируются по известной положительной длительности. Короткое окно основное; длительности не зашиты в код.
- Основной показатель переключается кликом по подписи; остальные окна не суммируются и не усредняются.
- Остаток `clamp(100 − usedPercent, 0, 100)`. Null, отсутствующее поле и неверный тип дают «нет данных».
- Пустой корректный ответ очищает старые окна. Сбой транспорта сохраняет последние данные, дату успешного обновления и отметку устаревания.
- Уведомление обновляет только полученные группы. Полный ответ заменяет снимок целиком.
- Восстановление лимита: остаток вырос и источник прислал более позднюю границу сброса. Проход локальных часов через reset сам по себе не наполняет кружку.
- Первый ответ отображается без анимации «сброса». Последующие изменения интерполируются плавно. Декоративные эффекты не меняют процент.
- Нулевой остаток: пустая кружка с подписью 0%. Неизвестный остаток: нейтральный контур и «нет данных».
- Подсказка содержит оба окна, даты сброса, время последнего ответа и состояние соединения.

Проверки модели охватывают clamp, null, неверные типы, изменённые длительности, несколько групп,
legacy-ответ, исчезнувшую группу, потерю связи, частичные уведомления и подтверждение сброса.
