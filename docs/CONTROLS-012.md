# Управление в 0.1.2

В настройках → «Лимиты» добавлен выбор 2, 5, 10, 30 или 60 секунд при показе виджета.
Настройка сохраняется в `refreshSeconds`, применяется без перезапуска процесса Codex;
при скрытии остаётся 300 секунд. По умолчанию — 10 секунд. После ошибок действует увеличение задержки.

Правый клик по незакреплённой кружке обрабатывается через `WM_NCRBUTTONUP`:
эта часть окна возвращает `HTCAPTION` для перетаскивания и раньше не открывала пользовательское меню.
Правый клик по подписи и клавиатурное контекстное меню продолжают работать.

Подсказка использует задержку 800 мс, игнорирует дрожание курсора в пределах 4 DIP,
фиксируется на месте при показе и скрывается при значимом движении, уходе курсора, перетаскивании и открытии меню.
Позиция и активация больше не обновляются на каждое сообщение мыши.
Для сравнения задержек есть режимы `hover-legacy`, `hover300`, `hover800`, `hover1200`:
они воспроизводят одинаковый шестисекундный сценарий движений и остановок внутри приложения,
вызывая настоящие Win32 API подсказки без перемещения системного курсора.

Проверено через computer-use: меню открылось правой кнопкой непосредственно по жидкости при `locked=false`;
в списке показаны все пять частот, выбор 2 секунд сохранился в JSON. Затем восстановлено 10 секунд.
Эта проверка выполнена в `--inspect` (отличается только доступностью окна для инструментов инспекции).
CTest проверяет сохранение всех частот, расписание, короткое движение, задержку и отмену подсказки.
Результаты повторных нагрузочных измерений публикуются отдельно после оптимизации.
