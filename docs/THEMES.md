# Настройки и пресеты

Внешность изменяется в окне настроек без пересборки. Ползунки дают немедленный предпросмотр на виджете;
кружка и минималистическое кольцо используют одну модель лимитов. Во вкладке «Лимиты» включается демонстрация.
Обычный режим запрашивает данные Codex; демонстрация не запускает Codex и явно подписывает значения.

Настройки: `%LOCALAPPDATA%/CodexBeerWidget/settings.json`.
Пресеты: `%LOCALAPPDATA%/CodexBeerWidget/presets/*.json`.
Кнопка сохранения создаёт собственный пресет, загрузка применяет только оформление и не меняет аккаунт,
положение окна, горячую клавишу или автозапуск. Стандартное оформление восстанавливает параметры темы.

Формат пресета: `version`, `name`, `theme`. Тема содержит:

- `resources.geometry`: `beer-mug` или `ring`, встроенная векторная геометрия;
- `fillArea`: left/top/right/bottom в системе 240×300; область ограничена внутренней полостью кружки;
- `liquidColor`, `textColor`: целое RGB 0…16777215;
- `glassAlpha`, `liquidAlpha`, `foam`, `waves`: 0…1;
- `bubbles`: 0…24, `transitionSeconds`: 0.1…5, `textSize`: 10…28;
- `showPercent`, `decoration`: логические значения.

`ring` сохраняется для совместимости; явный `resources.geometry` имеет приоритет.
Неизвестные поля игнорируются, числа ограничиваются допустимыми диапазонами, файлы больше 64 КиБ отклоняются.
Исполняемых скриптов и загружаемых из сети ресурсов в темах первой версии нет.
