# CPU в версии 0.2.1

Основной вывод снова использует Direct3D/DirectComposition. Режим пропуска кликов использует Direct2D/DIB, чтобы не читать кадры с GPU. `--software` принудительно выбирает программный вывод. `--gpu` имеет приоритет для обычного окна.

При обычном скрытии сохраняются графическое устройство, кисти, шрифты и текстовые раскладки. Кадровый таймер останавливается. При сне, блокировке и выключении дисплея устройство освобождается. Скрытый первый запуск по-прежнему не создаёт графику.

Координаты 201 точки кольца вычисляются один раз на Renderer. Неподвижное кольцо больше не запускает декоративный таймер. Плавный переход уровня сохранён.

## Замеры

17 сентября 2026, Ryzen 7 7735HS, 16 логических CPU, Windows 11. Высота 240 DIP, DPI 120. Два парных прогона по 15 секунд после 2 секунд прогрева. Во второй паре порядок версий обратный. Фоновые приложения не изолированы. Данные демонстрационные; процессы Codex исключены.

CPU указан как процент одного логического ядра. Значения: среднее и диапазон двух прогонов. MiB = 1024² байт.

| Режим | CPU до, % ядра | CPU после, % ядра | Рабочая память до / после, MiB | FPS до / после |
|---|---:|---:|---:|---:|
| 30 FPS | 8.13 (7.82–8.44) | 4.74 (3.64–5.84) | 27.15 / 50.77 | 29.18 / 26.80 |
| 60 FPS | 17.50 (15.20–19.79) | 8.96 (8.55–9.38) | 27.05 / 48.61 | 57.93 / 57.96 |
| Пропуск кликов, 30 FPS | 10.10 (9.27–10.93) | 9.48 (8.44–10.53) | 26.78 / 29.29 | 29.20 / 27.18 |

Рост памяти ожидаем: теперь приоритет CPU. Для пропуска кликов алгоритм вывода не изменён; различие коротких измерений не доказывает улучшения этого режима. Первичные непарные прогоны также сохранены в JSON.

В обычном режиме фактический FPS после изменений ниже: это не сравнение при строго одинаковой частоте кадров. В плавном режиме FPS сопоставим: 57,93 и 57,96; CPU снизился примерно на 49%.

Отдельные 8-секундные проверки: кольцо, скрытие после анимации и скрытый запуск дали 0 кадров, 0 мс интервала таймера и 0% CPU. После обычного скрытия Renderer сохранён; при скрытом запуске отсутствует. Эти проверки подтверждают остановку анимации, но не измеряют полный цикл физического сна Windows.

Тесты: Release, CTest 2/2, программный вывод через `--software`. Через интерфейс проверены включение и отключение пропуска кликов, корректный кадр после возврата к GPU, скрытие горячей клавишей и повторный показ из кеша. Настройки пользователя не изменены. Данные получены на одном компьютере, не гарантируют такие же значения на других системах.

## Повторение

```powershell
./tools/performance-suite.ps1 -Executable ./build/Release/CodexBeerWidget.exe -Tag cpu -Seconds 15 -Repeats 2 -Modes static,normal,smooth,clickthrough
./tools/performance-suite.ps1 -Executable ./build/Release/CodexBeerWidget.exe -Tag lifecycle -Seconds 8 -Repeats 1 -Modes ring,hidden-warm,hidden
```

Перед замером закройте обычный виджет. Для парного сравнения чередуйте сохранённый EXE 0.2.0 и новый EXE в каждом режиме, меняя порядок во второй паре. Настройки пользователя в benchmark-режимах не сохраняются.
