# Проверка выпуска 0.1.0

Первый выпуск — приватная предварительная версия Windows x64. EXE не подписан.
Codex CLI поставляется отдельно; совместимость подтверждена с 0.153.4 и существующим входом ChatGPT.

| Проверка | Результат |
|---|---|
| Независимый запрос лимитов, повторный запуск App Server | Пройдено на рабочем компьютере |
| Изменение лимитов при использовании Codex Desktop | Подтверждено опросом; уведомления не наблюдались |
| Разбор протокола, группы, пропуски, ошибки, остаток и сброс | Автоматические тесты CTest |
| Кружка и кольцо, настройки, сохранение пресета | Проверено через интерфейс |
| Перетаскивание, размер 80 и 400 DIP, скрытие горячей клавишей | Проверено через интерфейс |
| Нагрузка скрытого, статического, анимированного режимов | [Условия и числа](PERFORMANCE.md) |
| Работа без сети / истёкшая авторизация | Ошибки покрыты моделью; реальный сценарий ещё не проверен |
| Физическое прохождение кликов и отсутствие перехвата фокуса | Требует проверки в обычном режиме |
| Несколько физических мониторов, смена DPI и отключение монитора | Требует проверки |
| Реальный сон, блокировка и выключение дисплея | Требует проверки |
| Чистая Windows без инструментов разработки | Требует отдельного компьютера или VM |

Непроверенные сценарии нельзя считать пройденными на основании успешной компиляции.
Не следует выходить из аккаунта, расходовать лимит или отключать сеть пользователя ради автоматической проверки.

## Приёмка на отдельной Windows

1. Распаковать ZIP в постоянную папку обычного пользователя. Установить совместимый Codex CLI и войти через ChatGPT.
2. Запустить EXE, проверить оба остатка и даты сброса через подсказку. Закрыть и запустить повторно.
3. Открыть текстовый редактор под виджетом. Проверить клики снаружи, в отверстии ручки и сквозь всю кружку при включённом пропуске кликов. Проверить набор текста во время обновления.
4. Переместить виджет между мониторами с разными DPI, изменить размер, отключить второй монитор. Проверить «Вернуть на основной экран» и повторный запуск.
5. Скрыть, заблокировать, выключить дисплей и отправить Windows в сон. После восстановления проверить анимацию и обновление данных.
6. На тестовой машине проверить отключение сети и истёкший вход: последние значения помечаются устаревшими, неизвестные не превращаются в 0%.
7. Включить автозапуск, перезапустить Windows, затем отключить автозапуск и проверить удаление записи.

Публичный стабильный выпуск требует завершения этой приёмки и решения о цифровой подписи.
