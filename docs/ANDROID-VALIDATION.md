## Расход relay

Локальный Windows-процесс Node 24.20.0, HTTPS, SQLite; без клиентов и Firebase.
После трёх секунд запуска замер за 30 секунд: CPU **0,0% одного ядра**,
working set **54,9 МиБ**, private bytes **29,5 МиБ**. Это измерение простоя,
не суммарный расход Windows-виджета, Codex, relay и Android и не нагрузочный тест.
Исходные числа: локальный `.local/relay-benchmark.json`; процесс после замера остановлен.

## Ограничения preview

Локальный relay доступен телефону только через LAN/VPN. FCM не создаёт сетевой маршрут.
Без Firebase фоновое обновление — WorkManager, минимум 15 минут, без гарантии точного срока.
Открытое приложение и активный overlay используют WSS; экран выключен — overlay прекращает подписку.
Windows опрашивает Codex с выбранным интервалом, поэтому realtime ограничен свежестью источника.
Ни установщик, ни программа не меняют доверенные сертификаты и правила firewall автоматически.

Debug APK подписан временным ключом CI. Между независимыми сборками может понадобиться
удаление приложения с потерей локального pairing. Для стабильных обновлений нужен постоянный
закрытый ключ выпуска. Секреты Firebase и pairing не включены в репозиторий или артефакты.
