# Codex Beer Widget

Нативный виджет Windows: количество пива показывает оставшийся процент лимита Codex.
Основной показатель — короткое окно, дополнительная шкала — длинное. Точные токены не вычисляются.

Разработка: C++20, Win32, Direct2D, DirectComposition, CMake, MSVC.
Нужен установленный Codex с действующим входом в ChatGPT. Авторизацией управляет Codex.

Проект находится в разработке. [Этапы и статус](docs/ROADMAP.md), [правила работы](CONTRIBUTING.md).
