# Codex Beer Widget

Нативный виджет Windows: количество пива показывает оставшийся процент лимита Codex.
Основной показатель — короткое окно, дополнительная шкала — длинное. Точные токены не вычисляются.

## Запуск

1. Скачайте ZIP из [Releases](https://github.com/szanko02/codex-beer-widget/releases), распакуйте в постоянную папку.
2. Нужен установленный Codex CLI с действующим входом через ChatGPT. Проверенная версия — 0.153.4.
3. Запустите `CodexBeerWidget.exe`. Установка и права администратора не нужны.

Предварительная версия 0.2.0, Windows x64. EXE не подписан. Проверено на Windows 11;
приёмка на чистой Windows, реальный сон и несколько мониторов ещё не завершены.
Виджет не включает Codex CLI и запускает его служебные процессы отдельно.
Авторизацией управляет Codex; виджет не копирует токены входа.

## Управление

| Действие | Как выполнить |
|---|---|
| Переместить | Перетащить кружку |
| Изменить размер | Ctrl + колесо или ползунок в настройках |
| Переключить главное окно лимита | Нажать подпись под кружкой |
| Скрыть / показать | Ctrl + Alt + B (изменяется в настройках) или значок в трее |
| Оформление и поведение | Правый клик по кружке или значку в трее → «Настройки» |
| Вернуть потерянный виджет | Трей → «Вернуть на основной экран» или снова запустить EXE |

Подсказка появляется после остановки курсора примерно на 0,8 секунды и показывает оба остатка,
время сброса и последнее обновление. Небольшое дрожание курсора не перезапускает ожидание.
При потере связи сохраняется последнее значение с отметкой «устарело»; отсутствие данных обозначено отдельно.
Опрос при показе: 2, 5, 10, 30 или 60 секунд — выбирается в настройках, по умолчанию 10.
При скрытии — раз в пять минут, после ошибок задержка увеличивается.
Уведомления Codex об изменениях обрабатываются дополнительно, но их доставка от Desktop не гарантирована.
Уровень пропорционален остатку: 1 процентный пункт соответствует 1% рабочей высоты заполнения.

Настраиваются цвета, прозрачность, пена, пузырьки, волны, текст и скорость переходов.
Есть кружка, кольцо, собственные пресеты, фиксация положения, пропуск кликов и необязательный автозапуск.
Экономичный режим включён по умолчанию; декоративная анимация доступна до 30 или 60 FPS.
Версия 0.2.0 использует Direct2D с небольшой программной поверхностью для уменьшения памяти.
Постоянная анимация при этом может потреблять больше CPU: для аппаратной отрисовки доступен запуск
`CodexBeerWidget.exe --gpu` после выхода из уже запущенного виджета. В экономичном режиме кадры
обновляются только при изменениях. Иконки виджета, диагностической утилиты и тестов встроены в EXE.
Настройки и пресеты хранятся в `%LOCALAPPDATA%\CodexBeerWidget`.

Если Codex не найден, задайте `CODEX_WIDGET_CODEX_PATH` — полный путь к нативному `codex.exe`.
Скрипты `codex.cmd` и `codex.ps1` не запускаются. Демонстрация доступна в настройках → «Лимиты»
или через `CodexBeerWidget.exe --demo`; она не расходует лимит.
